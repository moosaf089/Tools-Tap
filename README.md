## AI image tools backend

High-resolution AI Background Remover, AI Image Upscaler, and Line Art Upscaler use the optional server-side API. GitHub Pages cannot run Python processing by itself. Follow `AI-BACKEND-SETUP-URDU.txt` to deploy the `ai-backend/` folder, then set the public HTTPS base URL in `ai-config.js`. Until configured, the tools use conservative browser limits to reduce memory failures. Free hosting is not unlimited and may be slow or sleep when idle.
