MEMORY SAFETY / DEPLOYMENT
- High-resolution AI processing must run on the separate Python service in `ai-backend/`; GitHub Pages cannot run that Python server.
- `ai-config.js` is intentionally left with a blank URL. Until a server is deployed and its HTTPS base URL is set there, the tools use conservative browser-only limits to reduce out-of-memory crashes.
- Follow `AI-BACKEND-SETUP-URDU.txt`. Free CPU hosting may be slow, may sleep when idle, and is not unlimited. No model can promise perfectly pixel-free 800% zoom for every source image.
